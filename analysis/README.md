# Research archive

## Published

- [Decompiled source index](../docs/source-index.md): 256 C exports across applications, ROM modules and historical baselines.
- [corpus/](corpus): module/data inventories, dependencies, imports, resources and source hashes.
- [functions/](functions): address boundaries, calls and labels; labels can be hypotheses.
- [strings/](strings): static extracted text references.
- [firmware/](firmware): contract evidence, instruction traces, bounded fixture results and decoder patches.
- [Research index](../docs/research.md): application, Bluetooth, USB, UI, updater, boot and driver notes.

## Interpretation

- Inventoried, disassembled and decompiled do not mean fully understood or tested on hardware.
- Read each report's scope, assumptions and unresolved behavior before reusing a finding.
- Research drafts are not necessarily included in a release. The release notes, complete member hashes and edit plan define the shipped changes.
- The notes preserve their original language and historical draft status. Current English release/development guides describe the supported workflow.
- Local artifact links in historical notes may require original firmware inputs or regenerated outputs.

## Generated locally

- Native firmware binaries, LGUs, full assembly dumps, Ghidra databases and downloaded vendor runtimes.
- Temporary extraction files, logs, private session checkpoints and old README copies are excluded.
- Setup and regeneration commands are in the [development guide](../docs/development.md).
